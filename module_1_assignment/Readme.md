# Module 1 Assignment: Introduction to OOP Concepts in C++ for Robotics

### Objective
This assignment introduces basic Object-Oriented Programming (OOP) concepts using C++ within a robotics context. Series of C++ programs to simulate robotics behavior, utilize sensor data, and demonstrate fundamental OOP principles are created.

### Components
The assignment consists of two main folders - include and src - that contain the interfaces and implementations of
- Robot
- Sensor
- Main

All components fulfil all tasks required to complete the objective

### How to compile
In module_1_assignment directory
```
cd ${PWD}/src
make
```

### How to Run
In module_1_assignment directory
```
cd ${PWD}/src
./mymain
```
